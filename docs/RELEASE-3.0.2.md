# SX-RPGInventory 3.0.2

修复 1.20.1 服务端物品保存时错误进入组件编解码的问题。组件编解码恢复以 1.20.5 为版本边界；旧式完整 NBT 编解码支持 1.17 起的新 NMS 包名，并按唯一方法签名解析物品保存与 DataVersion 写入，兼容不同映射名称。若方法签名存在歧义则拒绝保存，避免写入损坏数据。

## 安装

停服备份配置与数据库，将旧插件 JAR 替换为 `SX-RPGInventory-3.0.2.jar`，然后重启。主包包含 bStats、数据库驱动等运行依赖。`api`、`plain` 和 `sources` 包不能作为服务端插件安装；保留一份主插件 JAR。

## 验证范围

使用 JDK 25 执行完整 Gradle 构建成功，104 项测试中 88 项通过、16 项跳过、0 失败。新增回归覆盖组件版本边界、SRG 方法签名、歧义拒绝和静态工厂排除。已核验主包插件版本与 bStats、HikariCP 依赖。PRTS/Arclight 1.20.1 的实服启用、物品保存与重登恢复尚未验证，不将历史其他服务端测试视为本版本实测。

附件提供完整插件、开发用 API 包及 SHA-256 校验文件。未发布远程 Maven 制品。
